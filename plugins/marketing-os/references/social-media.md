## Instagram

### Formatos e Especificações

| Formato | Dimensões | Duração | Caracteres |
|---------|-----------|---------|------------|
| Feed Quadrado | 1080x1080px | - | 2.200 (125 visíveis) |
| Feed Retrato | 1080x1350px | - | 2.200 |
| Stories | 1080x1920px | até 60s por story | - |
| Reels | 1080x1920px | até 3 min (15-90s retém mais) | 2.200 |
| Carrossel | 1080x1080/1350px | até 20 itens | 2.200 |

### Estrutura de Post - Feed

```
[HOOK] Primeira linha que para o scroll (emoji opcional)

[CORPO] Desenvolver o tema com:
- Valor prático
- Storytelling
- Dados/provas

[CTA] Chamada para ação clara

.
.
.

#hashtags (5-15 relevantes)
```

### Estrutura de Carrossel

```
SLIDE 1 (CAPA):
- Headline impactante
- Promessa clara
- Design que chama atenção

SLIDES 2-8 (CONTEÚDO):
- 1 ideia por slide
- Texto legível (fonte 24pt+)
- Progressão lógica

SLIDE 9 (RESUMO):
- Recap dos pontos principais
- Reforço do valor

SLIDE 10 (CTA):
- Ação específica
- Salvar/Compartilhar/Seguir
```

### Reels - Estrutura

```
0-1s: HOOK visual/sonoro forte
1-3s: Setup do problema/tema
3-10s: Conteúdo principal
10-15s: Payoff/conclusão + CTA

Elementos essenciais:
- Texto na tela (70% veem sem som)
- Transições dinâmicas
- Áudio trending quando possível
```

## LinkedIn

### Formatos e Especificações

| Formato | Dimensões | Caracteres |
|---------|-----------|------------|
| Post texto | - | 3.000 (140 preview) |
| Imagem | 1200x627px | 3.000 |
| Carrossel (PDF) | 1080x1080px | 3.000 |
| Vídeo | 1920x1080px | 3.000 |
| Article | - | Ilimitado |

### Estrutura de Post LinkedIn

```
[HOOK] Primeira linha forte (aparece no preview)
↳ Use quebra de linha para criar suspense

[CONTEXTO] Situação/problema

[INSIGHT] Sua perspectiva única

[DESENVOLVIMENTO] 3-5 pontos ou história

[CONCLUSÃO] Aprendizado/takeaway

[CTA] Pergunta ou call-to-action

#hashtag1 #hashtag2 #hashtag3 (máximo 5)
```

### Tipos de Conteúdo que Performam

1. **Histórias pessoais** - Vulnerabilidade profissional
2. **Lições aprendidas** - "O que eu gostaria de saber antes..."
3. **Contrarian takes** - Opiniões que desafiam o status quo
4. **Dados e insights** - Análises originais
5. **Celebrações** - Marcos e conquistas (com humildade)

### Estrutura de Carrossel LinkedIn

```
SLIDE 1: Título + gancho visual
SLIDES 2-8: 1 ponto por slide, design limpo
SLIDE 9: Resumo/conclusão
SLIDE 10: CTA + sobre você
```

### Melhores Horários LinkedIn

| Dia | Horários Premium |
|-----|------------------|
| Terça-Quinta | 7h-8h, 12h, 17h-18h |
| Segunda/Sexta | 10h, 12h |
| Sábado/Domingo | Evitar (baixo engajamento) |

## Twitter/X

### Especificações

| Formato | Limite |
|---------|--------|
| Tweet | 280 caracteres |
| Thread | 25 tweets |
| Imagem | 1200x675px |
| Vídeo | 2:20min |

### Estrutura de Tweet Viral

```
[HOOK] Primeira frase impactante

[CONTEÚDO] Conciso e específico

[CTA ou PUNCHLINE] Fechamento forte
```

### Estrutura de Thread

```
TWEET 1 (HOOK):
Promessa clara do que a pessoa vai aprender
"X coisas sobre Y que vão mudar como você Z:"

TWEETS 2-9 (CONTEÚDO):
- 1 ponto por tweet
- Exemplos concretos
- Sem filler words

TWEET 10 (FECHAMENTO):
- Recap
- CTA (follow, RT, bookmark)
- Link para recursos
```

### Fórmulas de Tweet

**Opinião Contrária:**
```
Unpopular opinion: [afirmação controversa]

Aqui está o porquê: [explicação]
```

**Lição Aprendida:**
```
[Resultado impressionante] me ensinou [número] lições:

1. [Lição]
2. [Lição]
...

A mais importante? [Destaque]
```

**Thread Teaser:**
```
Passei [tempo] estudando [tema].

Aqui estão [número] insights que a maioria não conhece:

🧵 (thread)
```

## TikTok

### Especificações

| Formato | Especificação |
|---------|---------------|
| Vídeo | 1080x1920px (9:16) |
| Duração | 15s-10min (ideal: 15-60s) |
| Legendas | 150 caracteres |
| Hashtags | 3-5 específicas |

### Estrutura de Vídeo TikTok

```
0-0.5s: HOOK instantâneo
        "POV:", "Você sabia que...", "Pare de fazer..."

0.5-3s: Setup rápido do tema

3-12s: Conteúdo principal
       - Cortes rápidos
       - Texto na tela
       - Energia alta

12-15s: Payoff + CTA
        "Salva pra não esquecer"
        "Segue pra mais"
```

### Tipos de Conteúdo que Viralizam

1. **Educational** - Dicas rápidas, hacks, tutoriais
2. **Trends** - Áudios e formatos virais
3. **Behind the scenes** - Autenticidade
4. **Storytimes** - Narrativas pessoais
5. **Duets/Stitches** - Reação a outros conteúdos

### Hooks que Funcionam

```
"Ninguém fala sobre isso, mas..."
"O erro que te impede de..."
"Se você é [persona], precisa saber..."
"3 segundos que vão mudar..."
"POV: você descobriu que..."
"Reply to @user: [resposta ao comentário]"
```

## Adaptação Cross-Platform

### Mesmo Conteúdo, Diferentes Formatos

| Conteúdo Original | Instagram | LinkedIn | Twitter | TikTok |
|-------------------|-----------|----------|---------|--------|
| Artigo 2000 palavras | Carrossel 10 slides | Post resumido | Thread 10 tweets | Vídeo 60s |
| Tutorial | Reels passo a passo | Carrossel PDF | Thread ilustrada | Vídeo com cortes |
| Case de sucesso | Carrossel antes/depois | Post storytelling | Tweet + imagem | Storytime |
| Dica rápida | Story | Post curto | Tweet único | Vídeo 15s |

### Regra de Adaptação

1. **Não copie e cole** - Adapte linguagem e formato
2. **Respeite a cultura** - Cada plataforma tem códigos
3. **Otimize para o algoritmo** - Formatos nativos performam melhor
4. **Timing diferente** - Espaçar publicações cross-platform
