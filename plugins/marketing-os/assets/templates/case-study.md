## FORMATOS DE CASE STUDY

### 📄 PDF (2-4 páginas)
- Formato mais comum
- Design visual profissional
- Fácil de compartilhar
- Ideal para B2B

### 🌐 Web Page
- SEO-friendly
- Pode incluir vídeo
- Interativo
- Fácil atualização

### 🎥 Vídeo (2-5 min)
- Mais engajante
- Mostra rostos reais
- Compartilhável em redes
- Complementa versão escrita

### 📊 Infográfico
- Resumo visual
- Foco em números
- Fácil de escanear
- Bom para redes sociais

### 📱 Versão Curta (1 página)
- Para uso em vendas
- Só resultados principais
- Leave-behind em reuniões
