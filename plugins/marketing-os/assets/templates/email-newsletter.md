# Template: Email Newsletter

## Informações do Template
- **Formato**: Newsletter semanal/quinzenal
- **Subject line**: 50 caracteres máximo
- **Preview text**: 90 caracteres

## EXEMPLOS DE SUBJECT LINES

### Curiosidade
```
• O que [grupo] sabe que você não sabe
• Isso muda tudo sobre [tema]...
• A verdade que ninguém conta sobre [tema]
```

### Benefício
```
• [Número] formas de [benefício] essa semana
• Como [resultado] sem [dor]
• O guia para [objetivo]
```

### Urgência/FOMO
```
• Você está perdendo isso em [tema]
• Última chance: [oportunidade]
• Antes que seja tarde...
```

### Pessoal
```
• {{nome}}, uma pergunta rápida
• Pensei em você quando vi isso
• Uma confissão...
```
