## Headlines que Convertem

### Fórmulas de Headline

#### Resultado + Tempo
```
[Resultado Desejado] em [Tempo Específico]

Exemplos:
• "Domine Excel em 30 Dias"
• "Perca 5kg em 4 Semanas"
• "Dobre Seu Faturamento em 90 Dias"
```

#### Sem + Dor
```
[Resultado] Sem [Dor/Obstáculo Principal]

Exemplos:
• "Inglês Fluente Sem Morar Fora"
• "Emagreça Sem Dietas Restritivas"
• "Venda Online Sem Aparecer"
```

#### Para Quem
```
Para [Persona] Que Quer [Resultado]

Exemplos:
• "Para Empreendedores Que Querem Escalar"
• "Para Mães Que Querem Trabalhar de Casa"
```

#### Número + Específico
```
[Número] [Método/Passos] Para [Resultado Específico]

Exemplos:
• "O Método de 5 Passos Para Criar Anúncios Que Vendem"
• "As 3 Estratégias Que Geram R$10k/mês"
```

#### Pergunta Desafiadora
```
E Se Você Pudesse [Resultado Desejado]?
Você Está Cometendo Estes [Número] Erros em [Área]?

Exemplos:
• "E Se Você Pudesse Viver do Seu Hobby?"
• "Você Está Cometendo Estes 5 Erros nas Suas Vendas?"
```

### Fórmulas de Subheadline

```
O [método/sistema] para [persona] que quer [resultado] sem [dor]

Descubra como [resultado] usando [método] mesmo que [objeção comum]

A forma mais [adjetivo: rápida/simples/eficaz] de [resultado] em [ano]
```

## Seções Essenciais

### 1. Seção de Problema/Dor

```
[HEADLINE DE EMPATIA]
"Você já se sentiu assim?"

[LISTA DE DORES]
• Dor 1 - situação específica
• Dor 2 - frustração comum
• Dor 3 - consequência do problema
• Dor 4 - medo ou preocupação

[VALIDAÇÃO]
"Se você marcou pelo menos 2, você está no lugar certo."
```

### 2. Seção de Solução/Produto

```
[HEADLINE DE APRESENTAÇÃO]
"Apresentamos [Nome do Produto]"

[DESCRIÇÃO EM 1 PARÁGRAFO]
O [produto] é [o que é] que ajuda [persona] a [resultado principal]
através de [diferencial/método].

[IMAGEM/VÍDEO DO PRODUTO]

[BENEFÍCIOS PRINCIPAIS - formato icon + texto]
✓ Benefício 1 - com resultado específico
✓ Benefício 2 - com resultado específico
✓ Benefício 3 - com resultado específico
```

### 3. Seção de Benefícios (Expandida)

```
[HEADLINE]
"O Que Você Vai Conquistar"

[BENEFÍCIO 1]
[Ícone] [Título do Benefício]
[2-3 linhas explicando o benefício e resultado]

[BENEFÍCIO 2]
...

[FORMATO ALTERNATIVO - Antes/Depois]
ANTES                    DEPOIS
• Situação ruim 1   →    • Situação ideal 1
• Situação ruim 2   →    • Situação ideal 2
```

### 4. Seção de Prova Social

```
[HEADLINE]
"Veja O Que Nossos Clientes Dizem"

[DEPOIMENTO 1]
"[Quote impactante com resultado específico]"
[Nome], [Cargo/Empresa ou Resultado]
[Foto real]

[DEPOIMENTO 2]
...

[LOGOS DE EMPRESAS] (se B2B)
"Empresas que confiam em nós"

[NÚMEROS]
• [X]+ clientes satisfeitos
• [X]% taxa de satisfação
• [X] anos no mercado
```

### 5. Seção de Como Funciona

```
[HEADLINE]
"Como Funciona em 3 Passos Simples"

[PASSO 1]
1️⃣ [Ação do usuário]
[Breve explicação]

[PASSO 2]
2️⃣ [O que acontece]
[Breve explicação]

[PASSO 3]
3️⃣ [Resultado obtido]
[Breve explicação]
```

### 6. Seção de Oferta/Preço

```
[HEADLINE]
"Investimento"

[ÂNCORA DE PREÇO - opcional]
Valor normal: R$ [preço riscado]

[PREÇO PROMOCIONAL]
Por apenas: R$ [preço]
ou [X]x de R$ [parcela]

[O QUE ESTÁ INCLUÍDO]
✓ [Item 1] - valor R$XX
✓ [Item 2] - valor R$XX
✓ [Bônus 1] - valor R$XX
✓ [Bônus 2] - valor R$XX

Valor total: R$ [soma]
Você paga apenas: R$ [preço final]

[CTA BUTTON]

[GARANTIA]
🛡️ Garantia de [X] dias
Teste sem risco. Se não gostar, devolvemos 100% do seu dinheiro.
```

### 7. Seção de FAQ

```
[HEADLINE]
"Perguntas Frequentes"

[PERGUNTA 1]
❓ Pergunta comum sobre objeção/dúvida?
[Resposta direta que elimina a objeção]

[PERGUNTA 2]
❓ Funciona para [situação específica]?
[Resposta que mostra aplicabilidade]

[PERGUNTA 3]
❓ Quanto tempo até ver resultados?
[Resposta com expectativa realista]

[PERGUNTA 4]
❓ E se não funcionar para mim?
[Resposta sobre garantia/suporte]
```

### 8. Seção de CTA Final

```
[HEADLINE DE URGÊNCIA]
"Garanta Sua Vaga Agora"

[RESUMO DO VALOR]
Tudo isso por apenas R$ [preço]

[CTA BUTTON GRANDE]

[ELEMENTOS DE URGÊNCIA]
⏰ Oferta válida até [data]
🔥 Restam apenas [X] vagas

[SELOS DE SEGURANÇA]
[Compra segura] [Garantia] [Pagamento seguro]
```

## Copy de Conversão

### Princípios de Copy que Vende

1. **Benefícios > Features**
   - ❌ "Curso com 40 horas de conteúdo"
   - ✅ "Domine a habilidade que vai dobrar seu salário"

2. **Específico > Genérico**
   - ❌ "Ganhe mais dinheiro"
   - ✅ "Gere R$5.000 extras por mês"

3. **Você > Nós**
   - ❌ "Nós oferecemos suporte 24h"
   - ✅ "Você tem suporte sempre que precisar"

4. **Ativo > Passivo**
   - ❌ "Os resultados serão alcançados"
   - ✅ "Você vai alcançar resultados"

### Power Words por Categoria

| Urgência | Exclusividade | Confiança | Valor |
|----------|---------------|-----------|-------|
| Agora | Exclusivo | Garantido | Grátis |
| Hoje | Limitado | Comprovado | Bônus |
| Imediato | Único | Testado | Incluso |
| Última chance | Especial | Seguro | Extra |
| Restam X | VIP | Certificado | Presente |

### CTAs que Convertem

| Tipo | Fraco | Forte |
|------|-------|-------|
| Genérico | "Clique aqui" | "Quero Começar Agora" |

## Tipos de Landing Page

### 1. Lead Generation Page

**Objetivo**: Capturar emails/contatos

```
Estrutura mínima:
- Headline com promessa do lead magnet
- 3-5 bullets de benefícios
- Formulário simples (nome + email)
- Imagem do lead magnet

Tamanho: Short (1 scroll)
Elementos: 1 CTA, mínimo de texto
```

### 2. Sales Page (Long Form)

**Objetivo**: Vender produto/serviço

```
Estrutura completa:
- Headline + subheadline
- Vídeo de vendas (opcional)
- Problema/Agitação
- Solução/Produto
- Benefícios detalhados
- Prova social extensa
- Oferta + bônus
- Garantia
- FAQ
- Múltiplos CTAs

Tamanho: Long (5-15 scrolls)
Elementos: Copy extenso, múltiplos CTAs
```

### 3. Webinar Registration Page

**Objetivo**: Inscrição em evento online

```
Estrutura:
- Headline com tema + benefício
- Data/hora do webinar
- O que vai aprender (3-5 bullets)
- Sobre o apresentador (mini bio)
- Formulário de inscrição
- Urgência (vagas limitadas)

Tamanho: Short-Medium (1-2 scrolls)
Elementos: Contagem regressiva, social proof
```

### 4. Click-Through Page

**Objetivo**: Aquecer antes da página de venda

```
Estrutura:
- Headline impactante
- Proposta de valor
- Principais benefícios
- CTA para próxima página

Tamanho: Very Short (acima do fold)
Elementos: Sem formulário, apenas botão
```

### 5. Thank You Page

**Objetivo**: Confirmar ação + próximo passo

```
Estrutura:
- Confirmação da ação
- O que esperar agora
- Próximos passos
- Oferta complementar (upsell)
- Social sharing

Tamanho: Short
Elementos: Instruções claras, oferta adicional
```

## Checklist de Conversão

### Antes de Publicar

- [ ] Headline clara e com benefício
- [ ] Proposta de valor única evidente
- [ ] CTAs visíveis e com copy de ação
- [ ] Prova social presente
- [ ] Garantia/redução de risco
- [ ] FAQ com objeções principais
- [ ] Mobile responsive
- [ ] Velocidade de carregamento <3s
- [ ] Formulários funcionando
- [ ] Tracking/analytics configurado

### Elementos que Aumentam Conversão

- [ ] Vídeo na hero section (+80% conversão)
- [ ] Depoimentos em vídeo
- [ ] Contagem regressiva (se genuína)
- [ ] Chat/WhatsApp para dúvidas
- [ ] Exit intent popup
- [ ] Selos de segurança
- [ ] Múltiplas opções de pagamento
