# 💰 Template: Página de Vendas (Sales Page)

Template completo para criar páginas de vendas de alta conversão.

---

## 📋 Estrutura da Sales Page

| Seção | Objetivo | Posição |
|-------|----------|---------|
| Hero | Capturar atenção, promessa | Topo |
| Problema | Criar identificação | Após hero |
| Solução | Apresentar o produto | Meio |
| Benefícios | Mostrar transformação | Meio |
| Prova Social | Construir confiança | Meio |
| Oferta | Detalhar o que está incluso | Meio |
| Preço | Revelar investimento | Antes do CTA |
| Garantia | Eliminar risco | Após preço |
| FAQ | Quebrar objeções | Final |
| CTA Final | Converter | Rodapé |

## ✅ Checklist da Sales Page

### Antes de Publicar

- [ ] Headline promete resultado claro
- [ ] Problema bem identificado (dores reais)
- [ ] Solução apresentada de forma clara
- [ ] Benefícios em formato de bullet points
- [ ] Mínimo 3 depoimentos com fotos
- [ ] Stack de valor (mostrar quanto valeria)
- [ ] Preço revelado gradualmente
- [ ] Garantia claramente explicada
- [ ] FAQ com objeções principais
- [ ] CTAs em múltiplos pontos da página
- [ ] Urgência/escassez (real)
- [ ] Mobile responsivo
- [ ] Tempo de carregamento < 3s
- [ ] Pixel de conversão instalado
