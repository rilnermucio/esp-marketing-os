# Template: Card Único por Nicho

Templates específicos de posts de imagem única para cada nicho, com estruturas, hooks, captions e CTAs otimizados.

---

## Visão Geral

```
CARD ÚNICO = Post de imagem/vídeo único no feed

QUANDO USAR:
├── Citações e frases impactantes
├── Anúncios e novidades
├── Memes e humor do nicho
├── Depoimentos de clientes
├── Perguntas de engajamento
├── Infográficos simples
└── Conteúdo de conexão pessoal

ESPECIFICAÇÕES:
├── Dimensões: 1080 x 1350 px (4:5) - recomendado
├── Alternativa: 1080 x 1080 px (1:1) - quadrado
├── Caption: até 2.200 caracteres
└── Hashtags: 10-15 relevantes
```

## Estrutura Universal de Caption

```
FÓRMULA PARA QUALQUER NICHO:

1. HOOK (Linha 1)
   └── Frase que para o scroll (máx 125 chars visíveis)

2. CONTEXTO (Parágrafo 2)
   └── Por que isso importa / situação

3. CONTEÚDO PRINCIPAL (Parágrafos 3-4)
   └── O valor / a informação / a história

4. APLICAÇÃO PRÁTICA (Lista ou parágrafo)
   └── O que o leitor pode fazer

5. CTA (Final)
   └── Pergunta ou ação específica

6. HASHTAGS (Após espaçamento)
   └── 10-15 hashtags relevantes
```

## Checklist por Nicho

### Antes de Publicar

- [ ] Hook é específico para o nicho?
- [ ] Conteúdo resolve problema real da audiência?
- [ ] Tom de voz está adequado ao nicho?
- [ ] CTA faz sentido para o objetivo?
- [ ] Hashtags são do nicho + gerais?
- [ ] Visual reflete a identidade visual?
- [ ] Caption tem espaçamento adequado?
- [ ] Horário é ideal para meu público?
